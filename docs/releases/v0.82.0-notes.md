## v0.82.0 — Docker Desktopでのローカル検証

Docker DesktopのLinuxコンテナで、CI相当の検証をローカル実行できるようにしました。Web移行の変更は含みません。

### 変更内容

- Dockerfile、Compose、実行スクリプトを追加。Node.js 22.12.0とElectronの実行環境をイメージ内に用意します。
- 整形・Lint、型チェック、回帰テスト、ビルド、画像メモリ検証（CPU・Electron 2048/3584）を一括実行します。
- Windows専用の更新スクリプト回帰テストを削除しました。Windows更新機能は維持していますが、その変更はWindows実機で別途検証が必要です。
- R2回帰テストが失敗状態の保存直後に非同期後処理を判定する競合を修正し、multipart中止要求を待って検証します。

### 付番と互換性

`0.81.1` → `0.82.0`（MINOR）。Docker Desktopによる新しい検証工程を追加するため、機能版を一度だけ更新します。開発段階のリリースです。アプリの保存形式・実行時機能・必須環境に変更はなく、データ移行は不要です。Schema、Template、Manifest、Compiler、Remote Workerの番号は変更しません。

### 利用と検証

```sh
docker compose run --build --rm test
```

Docker化とWindows専用テスト削除の各ブランチで、上記の全検証が成功しました。リリース準備後の0.82.0でも同じ全検証が成功しました。公開対象mainコミットのCI成功を確認してから公開します。外部CLI・ネットワーク接続・Windows更新操作の実機E2Eは今回の検証対象外です。
